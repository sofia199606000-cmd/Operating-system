### Словник основних англійських термінів

**Compression** — спосіб зменшення розміру файлу на диску за допомогою математичних розрахунків та алгоритмів.

**Archiving** — процес об'єднання багатьох файлів у один для зручного зберігання, резервного копіювання або розповсюдження із збереженням метаданих.

**Lossy Compression** — метод, при якому частина даних видаляється назавжди задля досягнення меншого розміру (наприклад, MP3 або JPEG).

**Lossless Compression** — метод, що дозволяє зменшити розмір файлу та згодом повністю відновити оригінал без втрати жодного біта інформації.

**Adaptive Compression** — сучасна техніка, при якій алгоритм аналізує файл під час роботи та постійно оновлює свій словник замін для більшої ефективності.

**Tar** — формат файлу та програма, що дозволяє маніпулювати групами файлів як одним цілим, зберігаючи структуру каталогів та права доступу.

**Gzip** — класична утиліта стиснення в Linux, що вирізняється високою швидкістю роботи та ефективним використанням пам'яті.

**Bzip2** — інструмент стиснення, який створює компактніші файли порівняно з gzip, але потребує більше часу на виконання операції.

**Xz** — сучасний механізм стиснення з дуже високим коефіцієнтом стиснення, що створює найменші файли, але має високі вимоги до оперативної пам'яті.

**Verbose** — параметр (наприклад, -v у команді tar), який наказує програмі демонструвати деталі виконання дій у терміналі.

## 2. Відповіді на питання:

**5.1. Яке призначення команд tar, xz, zip, bzip, gzip? Зробіть короткий опис кожної команди та виділіть їх основні параметри. Яким чином їх можна встановити**

Команда tar призначена для об'єднання багатьох файлів у один архів із збереженням їхніх прав доступу та метаданих. Вона використовує такі основні параметри, як -c для створення архіву, -v для відображення детального процесу (verbose), -f для вказівки імені файлу та -x для витягування даних. Утиліта gzip є класичним засобом стиснення, що використовує алгоритм DEFLATE і вирізняється високою швидкістю роботи. До її параметрів належать -d для декомпресії та цифрові прапорці від -1 (найшвидше) до -9 (найкраще стиснення). Команда bzip2 реалізує алгоритм Burrows-Wheeler, що забезпечує сильніше стиснення, ніж gzip, але потребує більше часу та пам'яті. Вона підтримує параметр -s для економії пам'яті та -d для розпакування. Утиліта xz використовує алгоритм LZMA2 для отримання найменшого розміру файлів, хоча процес стиснення є найбільш тривалим. Серед її параметрів — -e для екстремального стиснення та -l для перегляду статистики. Команда zip є універсальним засобом, що поєднує архівацію та стиснення. Усі ці інструменти зазвичай встановлені в Linux за замовчуванням, але їх можна інсталювати через стандартні менеджери пакетів (наприклад, apt або yum)


**5.2. Наведіть три приклади реалізації архівування та стискання даних різними командами.**

Для реалізації архівування та стиснення можна використовувати комбінацію команди tar з різними утилітами. Першим прикладом є створення архіву з використанням швидкого стиснення gzip за допомогою команди tar czvf compressed.tar.gz directory1. Другим варіантом є використання bzip2 для отримання більш компактного файлу командою tar cjvf bzipcompressed.tar.bz2 directory2. Третім прикладом є застосування найбільш ефективного стиснення xz через команду tar cJvf xzcompressed.tar.xz directory3, що ідеально підходить для довготривалого зберігання даних


**5.3. Яке призначення команд cat, less, more, head and tail? Зробіть короткий опис кожної команди та виділіть їх основні параметри. Яким чином їх можна встановити**

Команди для роботи з текстом дозволяють переглядати та маніпулювати вмістом файлів безпосередньо в терміналі. Команда cat використовується для виведення всього вмісту файлу на екран або об'єднання кількох файлів у один потік. Утиліти more та less призначені для посторінкового перегляду довгих текстів, причому less є більш функціональною, бо дозволяє гортати текст у обох напрямках. Команди head та tail слугують для виведення лише початкових або кінцевих рядків файлу відповідно (за замовчуванням 10 рядків). Ці інструменти є частиною базового набору системних утиліт і доступні в будь-якому дистрибутиві Linux без додаткового встановлення


**5.4. Поясніть принципи роботи командної оболонки з каналами, потоками та фільтрами**

Робота командної оболонки базується на перенаправленні стандартних потоків даних: введення (stdin), виведення (stdout) та помилок (stderr). Використання символів > та >> дозволяє спрямовувати вивід команди у файл, замінюючи його вміст або додаючи дані в кінець. Спеціальний файл /dev/null використовується для повного ігнорування непотрібних потоків даних. Канали або конвеєри (символ |) дозволяють передавати вихідні дані однієї команди як вхідні для іншої. Фільтри, такі як sort або wc, приймають потік тексту, обробляють його згідно з заданими правилами (наприклад, сортування або підрахунок рядків) і видають результат далі за ланцюжком.


**5.5. Яке призначення команди grep?**

Команда grep є спеціалізованим фільтром, призначеним для пошуку конкретних рядків або текстових шаблонів у файлах або вхідних потоках даних. Вона часто використовується в поєднанні з іншими командами через канали, щоб виокремити лише ту інформацію, яка відповідає заданому критерію пошуку, наприклад, для знаходження рядків з певним словом у великому лог-файлі.

## 5. Розгляньте наведені нижче приклади та поясніть, що виконують дані команди та який тип перенаправлення потоків вони використовують:

## Відповіді на контрольні запитання:

**1. Надайте порівняльну характеристику процесам стискання та архівування.**

   Архівування та стиснення — це два різні, але взаємодоповнюючі процеси обробки даних. Архівування полягає в об’єднанні багатьох окремих файлів і каталогів у один об’єкт (архів) із повним збереженням структури папок, прав доступу та метаданих, що значно полегшує перенесення або резервування груп даних. Натомість стиснення — це застосування математичних алгоритмів для усунення надлишковості в даних з метою зменшення їх фізичного розміру на диску. Архівування не обов'язково зменшує розмір файлів, воно лише організовує їх, тоді як стиснення фокусується саме на економії дискового простору та пропускної здатності мережі.


**2. Які програми, окрім наведених в роботі, можуть використовуватись для стискання та архівування файлів та каталогів в ОС Linux? Наведіть приклади та їх короткий опис.**

  Окрім стандартних tar, gzip, bzip2 та xz, в Linux широко використовуються інші інструменти. Наприклад, 7-Zip (p7zip) — потужна утиліта з відкритим кодом, що забезпечує дуже високий коефіцієнт стиснення у власному форматі .7z. Програма rar дозволяє працювати з архівами однойменного формату, які часто зустрічаються в середовищі Windows. Також існують спеціалізовані утиліти, як-от pigz (паралельна реалізація gzip), що прискорює процес на багатоядерних процесорах, та lbzip2, яка виконує аналогічну функцію для алгоритмів bzip2, значно скорочуючи час обробки великих масивів даних.

**3. Порівняйте алгоритми стискання, що використовуються в командах (програмах), використовуваних в Linux. Які з алгоритмів можна вважати найшвидшим та найефективнішим?**

  Серед розглянутих алгоритмів gzip вважається найшвидшим, оскільки він забезпечує високу швидкість як стиснення, так і декомпресії, що робить його ідеальним для повсякденних завдань, де час дорожчий за кожен зекономлений мегабайт. Алгоритм bzip2 пропонує краще стиснення, ніж gzip, але працює значно повільніше і потребує більше пам'яті. Найефективнішим з точки зору мінімізації розміру файлу є xz (алгоритм LZMA2), який створює найменші за обсягом архіви, хоча сам процес стиснення займає найбільше часу та системних ресурсів.

**4. Опишіть програмні засоби для стискання та архівування, що можуть бути використані у вашому мобільному телефоні.**

  На мобільних пристроях під управлінням Android або iOS функції архівування часто інтегровані в стандартні файлові менеджери (наприклад, застосунок «Файли»), які дозволяють створювати та розпаковувати ZIP-архіви. Для більш складних завдань існують сторонні додатки, як-от ZArchiver, який підтримує роботу з багатьма форматами (7z, rar, tar, xz), або RAR for Android від розробників оригінального WinRAR. Ці засоби дозволяють користувачам мобільних телефонів не лише стискати фото чи документи для відправки електронною поштою, а й керувати складними архівами із паролями або багатотомними структурами.

**5. Опишіть та порівняйте програмні засоби для стискання та (де)архівування даних у ОС сімейства Windows.**

  В ОС Windows найбільш розповсюдженим є вбудований засіб для роботи із ZIP-папками, який дозволяє базове стиснення без встановлення стороннього ПЗ. Однак більшість користувачів віддають перевагу потужнішим інструментам, таким як WinRAR, що відомий підтримкою власного формату .rar із можливістю відновлення пошкоджених архівів, або 7-Zip, який є безкоштовним та забезпечує кращу компресію у форматі .7z. Порівняно з системним засобом, ці програми працюють швидше, підтримують значно більше форматів (включаючи Linux-архіви .tar.gz чи .tar.bz2) та пропонують вищий рівень захисту даних за допомогою шифрування AES-256.

**6. Поясніть яким чином стиснення та архівування даних може бути використано для резервування даних. В яких ще задачах системного адміністрування воно може бути використано.**

  Для резервного копіювання ці процеси є критично важливими, оскільки архівування дозволяє зберегти цілісність всієї системи або окремого проекту в одному файлі з усіма правами доступу, а стиснення мінімізує обсяг сховища, необхідного для зберігання багатьох копій. У системному адмініструванні ці технології також використовуються для дистрибуції програмного забезпечення (упаковка вихідного коду чи бінарних файлів), автоматичної ротації та архівації лог-файлів для економії місця на сервері, а також для підготовки даних до передачі через мережу, що дозволяє значно зекономити пропускну здатність каналів зв’язку.

**7. Яке призначення директорії файлу /dev/null?**

  Файл /dev/null — це спеціальний віртуальний пристрій у Linux, який функціонує як «чорна діра» для даних. Будь-яка інформація, яка записується у цей файл, негайно відкидається і безповоротно зникає, а операція запису завжди вважається успішною. Системні адміністратори використовують його для перенаправлення непотрібних потоків виведення (stdout) або повідомлень про помилки (stderr), щоб вони не засмічували термінал під час роботи скриптів чи виконання фонових команд.

## Висновок 

The processes of archiving and compression have fundamental differences: compression is a method of reducing the size of a file on disk using mathematical algorithms and calculations , whereas archiving (such as creating a tar file) allows for the manipulation of many files in a filesystem, with intact permissions and metadata, as a single file. In addition to the basic utilities discussed, Linux environments often utilize tools like 7-Zip for high-ratio compression, RAR for compatibility with Windows-based archives, or pigz, which is a parallel implementation of gzip that significantly speeds up processing on multi-core systems. When comparing algorithms, gzip is categorized as the fastest method for both compression and decompression while remaining very resource-efficient. In contrast, xz (using the LZMA2 algorithm) is considered the most effective for achieving the maximum compression ratio and creating the smallest files, though it requires significantly more time and memory. On mobile devices, software such as ZArchiver or mobile versions of RAR and 7-Zip are commonly used to manage these compressed formats directly on a smartphone. In the Windows ecosystem, the primary tools include the built-in ZIP utility, WinRAR, and 7-Zip, which offer advanced features like AES-256 encryption and multi-volume archival support compared to standard system tools. In system administration, combining these technologies is critical for data backup, as it preserves directory structures and minimizes the storage space and bandwidth required for network communication. Furthermore, these tools are essential for log rotation and software distribution, where providing compact and integral data packages is a priority. The special file /dev/null serves as a virtual "black hole" in Linux; any data written to it is immediately discarded, making it a vital tool for redirecting and hiding unnecessary standard output or error messages during command execution
