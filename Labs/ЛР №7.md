## Завдання для попередньої підготовки

### Словник основних англійських термінів 

Shell script (шел-скрипт) — текстовий файл із командами, які виконуються послідовно в оболонці (shell).

Executable file (виконуваний файл) — файл, який має дозвіл на запуск.

Interpreter (інтерпретатор) — програма, яка виконує скрипт (наприклад, bash, sh).

Shebang (#!) — перший рядок скрипта, що вказує, який інтерпретатор використовувати.

Hash (#) — символ коментаря або частина shebang.

Bang (!) — символ у shebang, разом із # утворює #!.

chmod — команда для зміни прав доступу до файлу (наприклад, зробити файл виконуваним).

Permission denied — помилка, яка означає, що файл не має прав на виконання.

$PATH — змінна середовища, яка містить шляхи до виконуваних програм.

./ (current directory) — позначає запуск файлу з поточної директорії

Variable (змінна) — зберігає дані (наприклад, текст або числа).

Conditional (умова) — дозволяє виконувати різні дії залежно від умов (if, else).

Loop (цикл) — повторює виконання команд (for, while).

Automation (автоматизація) — виконання повторюваних задач за допомогою скриптів.

## Відповіді на наступні запитання:

1.1. Охарактеризуйте поняття скриптового сценарію у командній оболонці.

Скриптовий сценарій у командній оболонці — це звичайний текстовий файл, який містить послідовність команд для інтерпретатора, наприклад, Bash. Замість того, щоб щоразу вручну вводити команди по черзі в терміналі, користувач записує їх у цей файл, після чого система виконує їх автоматично, рядок за рядком. Такий підхід є основним інструментом для автоматизації рутинних завдань, системного адміністрування, виконання регулярного резервного копіювання та пакетної обробки даних.


1.2. Яким чином створюються та редагуються скрипти, що треба зробити щоб запустити скрипт?

Скрипти створюються та редагуються за допомогою будь-якого консольного або графічного текстового редактора, такого як nano, vim або gedit. Традиційно першим рядком у такому файлі вказується спеціальна конструкція shebang (наприклад, #!/bin/bash), яка повідомляє системі, який саме інтерпретатор потрібно використати для виконання коду. Для того щоб запустити створений скрипт як самостійну програму, спочатку необхідно надати цьому файлу права на виконання за допомогою команди chmod +x. Після цього сценарій можна виконати, вказавши прямий шлях до нього, наприклад, ввівши ./ім'я_скрипта.sh, якщо файл знаходиться у поточній директорії.


1.3. Які основні компоненти материнської плати ви знаєте? 

До основних компонентів материнської плати належить сокет процесора, який є місцем для встановлення центрального процесора, та слоти оперативної пам'яті для підключення відповідних модулів. Важливим елементом є чипсет — набір мікросхем, що керує потоками даних між процесором, пам'яттю та периферією. Крім того, на платі розміщені слоти розширення стандарту PCIe для відеокарт чи мережевих адаптерів, а також роз'єми SATA та M.2 для підключення жорстких дисків і твердотільних накопичувачів. Також обов'язковими компонентами є мікросхема BIOS або UEFI з батарейкою CMOS для збереження базових налаштувань, роз'єми живлення для з'єднання з блоком живлення та панель вводу-виводу із зовнішніми портами.


1.4. Коротко охарактеризуйте для яких пристроїв оперують поняттями MBR та GPT?

Поняттями MBR та GPT оперують виключно для постійних накопичувачів даних, до яких належать класичні жорсткі диски (HDD), сучасні твердотільні накопичувачі (SSD) та різноманітні змінні носії на зразок USB-флешок. Ці поняття позначають стилі розмітки диска або таблиці розділів, які визначають логічну структуру фізичного простору накопичувача та вказують системі спосіб завантаження. MBR є старішим стандартом із обмеженням обсягу диска до двох терабайтів та підтримкою лише чотирьох основних розділів, тоді як GPT — це сучасний стандарт, що працює в парі з UEFI, підтримує накопичувачі величезних обсягів і дозволяє створювати практично необмежену кількість розділів.


1.5. У чому суть операції монтування, для чого вона потрібна?

Суть операції монтування полягає в логічному прикріпленні файлової системи певного апаратного пристрою зберігання до порожньої папки в єдиному дереві каталогів операційної системи. В ОС типу Linux немає окремих літерних позначень дисків, як у Windows, тому все починається з єдиного кореневого каталогу. Монтування потрібне для того, щоб отримати фактичний доступ до даних на носії, оскільки до виконання цієї операції система бачить підключений диск чи флешку лише як фізичний блоковий пристрій, з якого неможливо читати файли або записувати їх. Тільки після монтування пристрою до обраної точки (наприклад, у каталог /mnt) користувач та програми отримують можливість повноцінно працювати з його файловою системою.

## Відповіді на контрольні запитання:

1. В чому відмінність між командами arch та lscpu?

Команда arch є максимально простою і виводить лише архітектуру процесора, наприклад, x86_64 або aarch64, що зручно для швидкої перевірки сумісності програм у скриптах. Натомість команда lscpu надає розгорнуту технічну інформацію про центральний процесор, включаючи кількість ядер та потоків, об'єм кеш-пам'яті різних рівнів, назву моделі, частоту та підтримувані технології віртуалізації, зчитуючи ці дані безпосередньо з системних файлів. 

2. Якою командою можна отримати інформацію про стан використання RAM поточною системою?

Найбільш вживаною командою для перевірки стану оперативної пам'яті є free, яку зазвичай запускають із ключем -h для відображення значень у зручних для читання одиницях (ГБ або МБ). Ця команда показує загальний обсяг RAM, кількість використаної, вільної та кешованої пам'яті, а також стан файлу підкачки (swap). Крім неї, можна використовувати інтерактивні утиліти top або htop для відстеження використання ресурсів у реальному часі.

3. Яким чином у скриптах можна опрацьовувати змінні та створювати розгалужені та циклічні сценарії?

У Bash-скриптах змінні створюються шляхом присвоєння значення імені без знака долара та пробілів, наприклад VAR=10, а звернення до них відбувається через символ $VAR. Для створення розгалужень використовується конструкція if [ умова ]; then ... else ... fi, де умови перевіряються в квадратних дужках. Циклічні сценарії реалізуються через for (для ітерації по списку файлів або чисел) або while (для виконання дій, поки певна умова залишається істинною), що дозволяє автоматизувати повторювані завдання.

4. Які команди для перегляду стану підключення периферійних пристроїв можна використати в терміналі?

Для моніторингу підключеного обладнання в Linux використовують спеціалізовані команди залежно від типу інтерфейсу: lsusb виводить список усіх пристроїв на шині USB (клавіатури, флешки, адаптери), lspci показує внутрішні пристрої на шині PCI (відеокарти, звукові карти), а lsblk дозволяє переглянути всі підключені блоки зберігання даних, такі як диски та розділи. Також корисною є команда dmesg, яка відображає повідомлення ядра про нещодавно підключену периферію.

5. Які можливості застунку gparted?

Програма GParted — це потужний графічний редактор розділів, який дозволяє створювати нові таблиці розділів, форматувати їх у різні файлові системи (ext4, NTFS, FAT32), а також видаляти або копіювати існуючі томи. Головною її перевагою є можливість безпечної зміни розміру (розширення або стиснення) та переміщення розділів на диску без втрати даних, а також встановлення спеціальних прапорців, таких як boot для завантажувальних секторів.
